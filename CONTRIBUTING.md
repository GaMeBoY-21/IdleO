# Contributing

The code here is published for transparency, under all rights reserved (see [LICENSE](LICENSE)). It is not open source, so we don't accept outside contributions: pull requests from people outside the team will be closed without review, and issues about features won't be acted on.

If you have found a security problem, please don't open an issue or a pull request. Report it privately, as [SECURITY.md](SECURITY.md) describes.

How the team itself works (branches, checks and pull requests) is in [CLAUDE.md](CLAUDE.md) and [docs/WORKFLOW.md](docs/WORKFLOW.md).
