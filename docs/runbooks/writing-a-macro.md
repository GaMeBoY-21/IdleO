# Writing a macro

A macro is a reply you send often, with its changes, applied in one step from the **Inbox**. You need `macros.manage`.

## Write it

In **Inbox**, **Macros**: choose the kind of work, name it, and write what it says. It can use `{{firstName}}`, `{{amount}}` and `{{link}}`. Anything else is refused, so a typo can't reach a person.

- **Words only go to kinds that can answer someone**: tickets and data requests sent as tickets. Others can only change state, tag or priority.
- **It can also** set the state (waiting on the person, or resolved), add a tag, or set a priority.
- **Write as we write**: short, plain, and with no promise a lawyer hasn't seen. Never put a person's details in the text: variables are for that.

## Editing

An edit is a new version. What was applied earlier stays in the audit log as the version it was, so you can always see what someone was sent.

## Applying

Press `m` on an item, or use its Macro button. The sheet shows the words as that person will read them. It's audited with the macro's version, and the reply goes through the ticket as any answer does.

For many items, select them and choose **Apply a macro**. Unlike the other bulk actions, a reply can't be undone, so read the preview.

## Retiring

Retire a macro you no longer want. It stops being offered, and its history stays.
